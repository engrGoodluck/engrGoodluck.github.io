# engrGoodluck — Portfolio Website

A responsive, static portfolio website built with HTML, CSS, and JavaScript for GitHub Pages.

## Files

- `index.html` — page content and project cards
- `style.css` — layout, colors, responsive styles
- `script.js` — mobile navigation menu

## Before publishing

1. In `index.html`, update the mobile app card with your real project name, description, technologies, and repository URL.
2. Replace the sample second project with a real project or remove that card until you have another project.
3. Replace `YOUR_EMAIL@example.com` with your preferred public contact email.
4. Update the skills and location text to reflect your actual experience and preferences.
5. Preview the site locally by opening `index.html` in a browser.

## Publish with GitHub Pages

1. Create a **public** repository named exactly `engrGoodluck.github.io` on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (not inside an extra nested folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to finish. Visit `https://engrGoodluck.github.io/`.

## Notes

- GitHub Pages serves static sites. It does not run a private backend server or database.
- Do not put API secrets, passwords, private keys, or environment files in this public repository.
- Google Fonts is used for typography; if unavailable, fallback fonts are defined.
